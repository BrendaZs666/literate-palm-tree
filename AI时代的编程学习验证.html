编程题 · Python90 / 100
题目：写函数 is_prime(n) 判断素数，是返回 True 否则 False。
学生代码：
def is_prime(n):
    if n <= 1: return False
    for i in range(2, n):
        if n % i == 0: return False
    return True
边界处理完整，测试用例通过 ✅
测试用例通过知识点：Python 函数与边界
编程题 · C++40 / 100
题目：写函数 swap(int* a, int* b) 交换两个整数。
学生代码：
void swap(int* a, int* b) {
    *a = *b;
    *b = *a;
}
第二行执行时原值已被覆盖，缺少临时变量。
错误类型：缺少临时变量指针语法正确知识点：C++ 指针与内存
编程题 · Java55 / 100
题目：写类 Student，含 name/age，方法 getDetails() 返回 "name, age"。
学生代码：getDetails() 方法体为 return;，未拼接 name 与 age，方法未返回正确内容。
错误标签：方法未返回正确内容知识点：Java 面向对象
